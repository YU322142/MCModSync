# MCSync 2.0 发布与运维

本文只描述当前 v5 工作流。旧 v1-v4 客户端升级见[旧版升级指南](中文使用指南.md)。

## 1. 发布前准备

发布输入必须是已经实际启动、进入测试服并完成关键玩法测试的客户端副本。不要直接拿下载缓存、服务端根目录或正在运行的实例发布。

发布前确认：

- Minecraft、加载器和 Java 版本正确。
- `mods/` 中不存在重复 Mod ID。
- MineAstr、沉浸画框等双端组件版本已经配对。
- 客户端没有正在运行的 Java 进程。
- 真实令牌、账户、世界、日志和地图缓存不在发布范围内。

## 2. 打开发布项目

运行：

```text
java -jar MCSync-2.0.0.jar
```

选择客户端的 Minecraft 根目录，而不是 `mods/` 子目录。发布项目保存编辑状态，不保存私有令牌。

## 3. Mods 页

Mods 页只处理 `mods/*.jar`。

每次扫描会计算当前文件哈希，并按以下顺序工作：

1. SHA-256 用于本地身份和旧 v5 精确对应。
2. SHA-512 查询 Modrinth 精确文件。
3. CurseForge fingerprint 查询精确文件。
4. 两个平台均无精确结果时回退本地托管。
5. 自制或手工适配 Mod 可以保持本地托管。

`modId` 只用于升级后的描述与选项继承，不能直接继承旧下载地址。重新匹配不会覆盖已经填写的中文描述；英文为空时才可补入平台英文说明。

删除 Mod 后重新扫描或导入旧 v5，不会恢复已经删除的条目。

## 4. 同步范围

按用途选择范围：

| 范围 | 建议策略 |
| --- | --- |
| `mods/` | managed |
| `resourcepacks/` | managed 或 optional |
| `shaderpacks/` | managed 或 optional |
| `kubejs/` | managed |
| `tacz/` | managed |
| `tlm_custom_pack/` | managed |
| `config/` | additive + 精确配置项 OTA |
| `defaultconfigs/` | additive |
| `options.txt` | first-install |

“managed”允许移除上一发布版拥有、但新清单删除的文件；不会删除没有所有权记录的玩家文件。

## 5. 配置 OTA

优先修改单个配置项，不要发布整个玩家配置目录。

每条操作应包含：

- 文件相对路径
- TOML/JSON/properties 类型
- 配置键路径
- 期望前像或允许值
- 目标值
- 是否要求重启

当前值不符合允许前像时操作失败闭锁，不猜测覆盖。世界 gamerule、玩家选项和存档数据不属于配置 OTA。

## 6. 可选内容

推荐 Mod、资源包和光影包会在首次出现或集合新增时显示选择界面，默认全选。玩家选择写入本地状态；仅描述或哈希变化不会反复弹窗。

必须内容不能取消。取消推荐内容不会削弱必须内容的严格校验。

## 7. 服务器列表

启用服务器列表同步时，发布器导出 `serverlist.txt` 和 `servers.dat`。客户端使用所有权台账只更新 MCSync 添加的条目，保留玩家自行添加或修改的服务器。

不要在公开测试仓库中提交真实私服地址；正式发布产物与公开源码是两套边界。

## 8. 验证与导出

导出前至少检查：

- schema 为 5
- releaseSequence 为当前发布序号
- minimumMCSyncVersion 合理
- 每个文件路径唯一
- 每个文件大小和 SHA-256 已锁定
- Mod 上游来源是精确哈希结果
- 非 Mod 文件没有模组站来源
- 配置操作有前像保护
- 管理范围没有存档和隐私目录

## 9. 上传顺序

1. 上传发布序号目录中的全部不可变文件。
2. 验证公网下载的大小与 SHA-256。
3. 上传服务器列表等辅助清单。
4. 最后原子替换 `mods-v5.json`。
5. CDN 存在缓存时确认新清单已生效。

不要先发布引用尚未上传文件的新清单。

## 10. 回滚

正常回滚应发布一个**更高 releaseSequence** 的修复清单，内容指向经过验证的旧文件。不要把云端序号调小；客户端会把它识别为降级攻击。

客户端本地事务失败时会使用备份和日志回滚。不要在游戏运行期间手动改写 `.modsync/` 状态。

## 11. 验收

至少测试：

- 全新客户端首次安装
- 旧 v5 客户端增量升级
- 推荐内容选择与取消
- Mod 改名但哈希相同
- Mod 升级后通过唯一 modId 继承描述并重新匹配
- 删除 Mod 后不被旧清单复活
- 镜像返回错误文件时回退官方来源
- 断网、下载截断和哈希错误时阻止启动
- 更新完成后重启进入游戏
